# VIRGO

macOS 13+ · Apple Silicon

## 받는 법

**`VIRGO-<판>-mac-arm64.dmg` 하나만 받으면 된다.**

1. [최신 릴리스](https://github.com/Dominic-YG-Lee/DL-Releases-VIRGO/releases/latest)에서 그 `.dmg`를 받는다
2. 열고 **VIRGO**을 **응용 프로그램** 폴더로 끌어 넣는다

끝이다. 릴리스에 있는 **나머지 파일은 앱이 혼자 업데이트할 때 쓰는 것**이라
사람이 받을 것이 아니다. 「Source code」도 깃허브가 자동으로 붙이는 것이고,
이 저장소에는 설치 파일 말고 아무것도 없다 — **소스 코드는 공개하지 않는다.**

https://dl-vale-virgo.pages.dev

## English

macOS 13+ · Apple Silicon

## How to install

**Download just one file: `VIRGO-<version>-mac-arm64.dmg`.**

1. Get that `.dmg` from the [latest release](https://github.com/Dominic-YG-Lee/DL-Releases-VIRGO/releases/latest)
2. Open it and drag **VIRGO** into **Applications**

That's all. The other files in a release are **used by the app's own updater**,
not by you. "Source code" is added automatically by GitHub, and this repository
contains nothing but installers — **the source code is not public.**

https://dl-vale-virgo.pages.dev
