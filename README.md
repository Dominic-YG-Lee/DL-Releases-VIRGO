# VIRGO

macOS 13+ · Apple Silicon

1. [Releases](https://github.com/Dominic-YG-Lee/DL-Releases-VIRGO/releases/latest)에서 `VIRGO-<판>-mac-arm64.dmg`를 받는다
2. 열고 **VIRGO**을 **응용 프로그램** 폴더로 끌어 넣는다

다른 파일은 앱이 스스로 업데이트할 때 쓴다 — 받을 필요 없다.

https://dl-vale-virgo.pages.dev

소스 코드는 공개하지 않는다. 이 저장소에는 설치 파일만 있다.

## English

macOS 13+ · Apple Silicon

1. Download `VIRGO-<version>-mac-arm64.dmg` from [Releases](https://github.com/Dominic-YG-Lee/DL-Releases-VIRGO/releases/latest)
2. Open it and drag **VIRGO** into **Applications**

The other files are used by the app's own updater — you don't need them.

https://dl-vale-virgo.pages.dev

The source code is not public. This repository holds installers only.
